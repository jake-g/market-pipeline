# Research / Strategy Report Prompt

This directory contains a strategy report generated by analyzing deep research through the `market-pipeline` ecosystem.

## Workflow

1.  **Initial Research (Optional but Recommended):**
    *   Use Gemini Advanced (or Deep Research) to create a comprehensive markdown document (e.g., `.DEEP_RESEARCH.md`).
    *   This document should gather facts, specifications, geopolitical context, and identify key publicly traded companies ("enablers").

2.  **Data Fetching:**
    *   Use the `market-pipeline` python scripts to pre-fetch real-time market data (prices, news, fundamentals) for the identified tickers.
    *   Example: `python market_fetcher.py --tickers AMD,BB,VSAT,AVAV,BAH,KULR`

3.  **Analysis Script Generation:**
    *   Create a specialized python script (e.g., `lucas_strategy_analysis.py`) inside this directory.
    *   Use `reports/report_utils.py` to generate:
        *   **Decision Trees (`setup_decision_tree_aesthetics`)**: Map out macro triggers, buy/sell conditions, and stop limits based on the research narrative.
        *   **Quantitative Plots**: Compare performance of the basket, or plot technical indicators like RSI vs Dist to 200MA for entry timing.

4.  **NotebookLM Synthesis (AI Insights):**
    *   Upload the initial `.DEEP_RESEARCH.md`, the output `REPORT.md`, and recent news TSVs to a dedicated NotebookLM notebook.
    *   Prompt NotebookLM:
        > Act as a senior geopolitical defense analyst and quantitative strategist. Synthesize the provided deep research on the [Topic] ecosystem with the latest market data and news.
        >
        > **Critical Directives:**
        > 1. Critically evaluate the provided decision tree and proposed portfolio basket. Directly CONFIRM or OPPOSE the strategic logic and timing.
        > 2. Cite specific evidence from the uploaded research documents and cross-reference with related news in your database (e.g., previous geopolitics reports).
        > 3. Provide a highly concise, bulleted readout of these insights.
        > 4. Output in rich markdown suitable for appending to a formal report.

5.  **Final Report Construction:**
    *   The python script should assemble:
        *   The narrative from the deep research.
        *   The generated Decision Tree and Plots.
        *   The fetched market data tables / metrics.
        *   The appended AI Insight synthesis from NotebookLM.
